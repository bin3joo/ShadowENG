# StyleEcho API 명세서

> 기준: `pipe/main.py` 현재 구현 기준  
> 대상 엔드포인트: `/api/v1/generate-reference`, `/api/v1/evaluate-audio`  
> **최종 업데이트: 2026-03-09 — 정책 반영 및 구조 재정리 기준 재동기화 ✅ 수정됨**

---

## 1. 개요

현재 `pipe/` 에 구현된 외부 공개 API 엔드포인트는 아래 2개입니다.

- `POST /api/v1/generate-reference`
- `POST /api/v1/evaluate-audio`

현재 구현 기준으로는 **Authorization 헤더를 사용하지 않습니다.**

---

## 2. 레퍼런스 생성

YouTube `video_id` 와 시간 구간을 받아 레퍼런스 스크립트, 문장별 파트 데이터, 단어 타임스탬프, F0/RMS 피처를 생성합니다.

`generate-reference` 는 **현재 구현 기준**으로 `video_id` 를 입력받습니다.  
Python 서버는 내부적으로 canonical YouTube URL 을 재조립하여 `yt-dlp` 와 자막 조회에 사용합니다.  
응답에는 추적/디버깅 편의를 위해 `video_id` 와 `youtube_url` 을 함께 포함합니다.  
**이 문단은 정책 반영으로 갱신됨 ✅ 수정됨**

### 2.1 HTTP Request

```http
POST /api/v1/generate-reference
Accept: application/json
Content-Type: application/json
```

---

### 2.2 Request Header

| 헤더명 | 필수 | 설명 |
| --- | --- | --- |
| Content-Type | Y | `application/json` |
| Accept | N | `application/json` |
| Authorization | N | 현재 미사용 |

---

### 2.3 Request Body

```json
{
  "video_id": "dQw4w9WgXcQ",
  "start_sec": 10.0,
  "end_sec": 20.0
}
```

| 필드명 | 타입 | 필수 | 설명 |

| start_sec | Number | Y | 시작 시각(초) |
| end_sec | Number | Y | 종료 시각(초) |

### 3. 유저 발화 분석 및 채점

유저 오디오와 레퍼런스 문장/피처/단어 타임스탬프를 받아 발화 평가 결과를 반환합니다.

### 3.1 HTTP Request

```http
POST /api/v1/evaluate-audio
Accept: application/json
Content-Type: application/json
```

---

### 3.2 Request Header

| 헤더명 | 필수 | 설명 |
| --- | --- | --- |
| Content-Type | Y | `application/json` |
| Accept | N | `application/json` |
| Authorization | N | 현재 미사용 |

---

### 3.3 Request Body

```json
{
  "user_audio": "base64-encoded-audio-or-url",
  "user_audio_format": "wav",
  "final_script": "I got it bad.",
  "features": {
    "f0_array": [120.1, 121.3, 119.8],
    "rms_array": [0.03, 0.05, 0.04]
  },
  "word_timestamps": [

      "word": "I",
      "start": 0.1,
      "end": 0.3,
      "score": 0.98
    },
    {
      "word": "got",
      "start": 0.31,
      "end": 0.5,
      "score": 0.95

}
```

### Request Fields

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| user_audio | String | Y | 유저 오디오. `http/https` URL 또는 base64 문자열 **✅ 수정됨** |

## 4. 참고 사항

- `evaluate-audio` 는 내부적으로 `pipeline.evaluate(user_audio_path, ref_data)` 를 호출합니다.
- 현재 구현 기준으로 `pause_similarity` 는 레퍼런스 `word_timestamps` 기반 pause 정보로 계산됩니다. `generate-reference` 응답의 `parts[]` 에 `pause_count` 도 포함됩니다. **✅ 수정됨**
- 현재 구현된 엔드포인트에는 `PATCH`, `PUT`, `DELETE`, `GET` API가 없습니다.
- 현재 구현된 엔드포인트는 모두 JSON Body 기반입니다.
- `generate-reference` 는 `video_id` 를 입력받고, Python 서버 내부에서 canonical YouTube URL 을 재조립합니다. **✅ 수정됨**
- `evaluate-audio` 는 `scores.total_score` 와 별도로 `pass_fail`, `pass_threshold` 를 함께 반환하므로, 백엔드는 AI 서버 판정을 사용하거나 자체 기준으로 재판정할 수 있습니다. **✅ 수정됨**
