# **ShadowEng 서비스 시연 흐름 및 화면별 조작 가이드**

## 1. 학습 세션 생성

조작 순서
좋아하는 영상으로 학습 시작하기 클릭\
유튜브 링크 붙여넣기 → 학습 시작하기 버튼 클릭\
학습 구간 선택해서 입력하기

## 2. 학습 과정 시연

하단 NavBar 를 통해 마이쉐도잉으로 이동\
마지막 문장 학습만을 남겨놓은 영상을 통해 학습\
마이크 버튼을 눌러서 녹음 후 다시 눌러서 녹음 종료를 통해 학습 진행\
학습 과정대로 진행 후\
최종 발표 리포트 확인

## 3. 학습 통계 사이트 시연

하단 NavBar 를 통해 학습 통계 페이지 진입\
캘린더에 있는 도장을 눌러 해당 날짜에 생성된 종합 리포트 확인

## 4. 게임 시연

하단 NavBar 의 홈화면을 터치하여 홈화면으로 이동\
화면 하단의 잉무를 꼬셔라 탭 터치 후 게임 화면으로 이동\
다시 한 번 화면을 터치하고 게임 레벨별 페이지로 이동\
게임 진행 방식은 메인 학습과 동일\
게임 종류 후 우상단의 트로피 아이콘을 클릭해 리더보드 진입
