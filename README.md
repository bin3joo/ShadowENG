## 기획 배경

영어 말하기 학습에서 쉐도잉은 원어민의 발화 속도, 억양, 표현을 자연스럽게 익힐 수 있는 효과적인 학습 방식입니다.  
그러나 실제로 사용자가 쉐도잉을 꾸준히 이어가기 위해서는 여러 장벽이 존재합니다.

기존 쉐도잉 학습은 학습할 영상을 찾고, 대본을 구하고, 문장을 반복 재생하며, 자신의 발화가 원본과 얼마나 다른지 직접 판단해야 합니다.  
이 과정은 학습자에게 높은 준비 비용을 요구하며, 피드백 없이 반복만 이어지는 경우 학습 효과를 체감하기 어렵습니다.

특히 발음이나 억양처럼 스스로 판단하기 어려운 영역은 사용자가 혼자 개선 방향을 찾기 어렵습니다.  
결국 쉐도잉은 좋은 학습법임에도 불구하고, 준비 과정의 번거로움과 피드백 부족으로 인해 지속성이 떨어지는 문제가 발생합니다.

ShadowENG는 사용자가 원하는 콘텐츠를 기반으로 바로 학습을 시작하고,  
AI 발화 분석을 통해 자신의 발화를 원본과 비교하며 개선할 수 있도록 돕습니다.

<strong>따라 말할수록 자연스러운 영어, ShadowENG이 함께합니다.</strong>

## 문제 정의 & 솔루션

### 문제
- 사용자가 쉐도잉을 시작하기 위해 영상, 대본, 반복 구간을 직접 준비해야 함
- 발음, 억양, 속도, 리듬 차이를 스스로 판단하기 어려움
- 반복 학습이 단조로워 장기적인 학습 지속성이 떨어짐
- 학습 결과가 기록되지 않아 자신의 성장 과정을 확인하기 어려움

### 해결
- 사용자가 원하는 콘텐츠 링크를 기반으로 쉐도잉 학습을 시작할 수 있는 흐름 제공
- STT, 발화 타임스탬프, 피치·에너지 분석을 활용한 AI 발화 피드백 제공
- 단계별 쉐도잉 학습과 게임 요소를 통해 반복 학습의 몰입도 강화
- 학습 기록, 복습, 캘린더, 리포트를 통해 지속적인 학습 관리 지원

### 핵심 가치
- **즉시성**: 원하는 콘텐츠로 바로 학습을 시작할 수 있도록 지원
- **피드백**: 사용자의 발화를 AI가 분석하여 개선 방향 제공
- **지속성**: 기록, 복습, 게임 요소를 통해 꾸준한 학습 유도

## 차별화 포인트

### 원하는 콘텐츠로 시작하는 쉐도잉 학습
정해진 교재나 영상이 아니라, 사용자가 직접 선택한 콘텐츠를 기반으로 쉐도잉 학습을 진행할 수 있습니다.  
이를 통해 사용자는 자신의 관심사와 수준에 맞는 영어 표현을 자연스럽게 학습할 수 있습니다.

### AI 발화 분석 기반 피드백
단순히 문장을 따라 말하는 것에 그치지 않고, 사용자의 발화를 원본 음성과 비교합니다.  
발음 유사도, 발화 속도, 리듬, 억양, 에너지 차이를 분석하여 사용자가 어떤 부분을 개선해야 하는지 확인할 수 있습니다.

### 단계별 학습 흐름
무자막, 자막, 부분 자막, 최종 평가로 이어지는 단계별 학습 구조를 제공합니다.  
사용자는 같은 문장을 여러 방식으로 반복하며 점진적으로 원본 발화에 가까워질 수 있습니다.

### 학습 지속성을 높이는 게이미피케이션
하트, 리그, Freeze와 같은 게임 요소를 통해 반복 학습의 지루함을 줄이고,  
학습자가 꾸준히 서비스를 다시 방문할 수 있도록 설계했습니다.

## 주요 기능

### 1) 콘텐츠 기반 쉐도잉 학습 시작
사용자는 학습하고 싶은 영어 콘텐츠를 선택하거나 링크를 입력해 쉐도잉 학습을 시작할 수 있습니다.  
서비스는 학습에 필요한 문장 단위 콘텐츠를 제공하고, 사용자가 바로 따라 말할 수 있는 학습 환경을 구성합니다.

### 2) 4단계 쉐도잉 학습
ShadowENG는 하나의 문장을 여러 방식으로 반복 학습할 수 있도록 4단계 학습 흐름을 제공합니다.

- 무자막 듣기
- 자막 확인 후 따라 말하기
- 부분 자막 기반 회상 학습
- 무자막 최종 발화 평가

이를 통해 사용자는 단순 암기가 아니라 듣기, 이해, 회상, 발화를 연결한 학습을 진행할 수 있습니다.

### 3) AI 발화 분석
사용자의 발화를 STT와 음성 분석 기술을 활용해 분석합니다.  
발화 속도, 단어별 발음, 강세, 억양, 에너지 흐름 등을 원본 음성과 비교하여 피드백을 제공합니다.

### 4) 단어 단위 피드백
문장 전체 점수만 제공하는 것이 아니라, 사용자가 어려워한 단어를 중심으로 세부 피드백을 제공합니다.  
길이, 강세, 억양 차이를 확인할 수 있어 사용자는 어떤 단어를 다시 연습해야 하는지 파악할 수 있습니다.

### 5) LLM 기반 표현 카드
학습 문장에서 활용할 수 있는 주요 표현을 AI가 카드 형태로 정리합니다.  
사용자는 문장 속 표현의 의미와 활용 맥락을 함께 학습하며, 단순 발화 연습을 넘어 실제 말하기 표현력을 확장할 수 있습니다.

### 6) 복습 및 학습 캘린더
사용자가 학습한 문장과 결과는 기록으로 저장됩니다.  
캘린더를 통해 학습 이력을 확인하고, 부족했던 문장을 다시 복습할 수 있습니다.

### 7) 학습 리포트
학습 결과를 기반으로 발화 정확도, 속도, 리듬, 발음 개선 필요 영역을 리포트 형태로 제공합니다.  
사용자는 자신의 학습 흐름과 변화 과정을 확인하며 다음 학습 방향을 설정할 수 있습니다.

### 8) 게임 기반 반복 학습
3문장 단위의 미션과 제한된 기회, 하트, 리그, Freeze 기능을 통해 학습에 게임 요소를 더했습니다.  
이를 통해 사용자가 반복 학습을 더 부담 없이 이어갈 수 있도록 설계했습니다.

## 실행 방법

### 사전 요구사항
- JDK 21+
- Docker / Docker Compose
- Python 3.10+
- Android Studio

### Backend / Infra 실행

```bash
cd Infra
docker-compose up -d --build
```

- Backend API: http://localhost:8080/api/v1/app
- Swagger UI: http://localhost:8080/api/v1/app/swagger-ui/index.html

### AI Server 실행

```bash
cd AI
bash setup.sh
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Windows 환경에서는 `setup.bat`을 사용할 수 있습니다.

- AI Server: http://localhost:8000

### Android 실행

Android Studio에서 `FE/` 디렉터리를 열고 앱을 실행합니다.

## 회고

## 회고

이번 프로젝트에서 기획과 디자인을 맡으며 개발자의 시각에서 벗어나, 사용자의 입장에서 서비스를 바라보는 경험을 했습니다. 이전에는 기능을 어떻게 구현할 수 있을지에 먼저 집중했다면, 이번에는 사용자가 왜 이 기능을 필요로 하는지, 어떤 흐름에서 불편함을 느끼는지, 그리고 어떤 화면 구성이 학습을 지속하게 만드는지에 집중했습니다.

ShadowENG의 출발점은 영어 말투를 비교하거나 원어민의 표현을 소개하는 숏폼 콘텐츠였습니다. 많은 사용자가 원어민의 실제 표현을 보고 “저렇게 말하고 싶다”는 니즈를 가지고 있다는 점에 주목했습니다. 이후 영어 발화 관련 콘텐츠를 조사하는 과정에서, 드라마나 영화 속 실제 발화를 따라 말하며 영어를 익히는 쉐도잉 학습 콘텐츠에도 꾸준한 수요가 있다는 것을 확인했습니다.

하지만 쉐도잉은 효과적인 학습 방식임에도, 말해보카나 스픽과 같은 영어 학습 앱에 비해 대중적으로 쉽게 이어지지 못하고 있었습니다. 그래서 실제 쉐도잉 학습 과정을 살펴보니, 사용자는 먼저 공부하고 싶은 영상의 대본을 찾아야 하고, 문장을 반복해서 따라 말하더라도 자신의 발화가 얼마나 정확한지 확인하기 어렵다는 문제가 있었습니다. 피드백이 부족하다 보니 학습 효과를 체감하기 어렵고, 자연스럽게 동기부여와 복습으로 이어지기 힘든 구조였습니다.

이 문제를 더 구체적으로 확인하기 위해 쉐도잉 관련 커뮤니티를 조사했습니다. 커뮤니티에서는 특정 콘텐츠의 대본을 찾거나, 함께 공부할 스터디를 구하는 글을 쉽게 볼 수 있었습니다. 이를 통해 사용자가 쉐도잉 학습에서 콘텐츠 준비의 번거로움과 피드백 부재를 실제로 겪고 있음을 확인했고, ShadowENG는 이 두 문제를 줄이는 방향으로 기능을 설계했습니다.

화면을 디자인할 때 가장 중요하게 생각한 부분은 학습 시작의 진입장벽을 낮추고, 학습이 자연스럽게 복습으로 이어지는 흐름을 만드는 것이었습니다. 사용자가 서비스에 진입했을 때 바로 영상 링크를 등록해 학습을 시작할 수 있도록 하고, 이전에 공부하던 영상은 이어서 학습할 수 있도록 구성했습니다. 또한 AI 분석 과정에서 사용자가 단순히 기다린다고 느끼지 않도록 분석 진행 상태와 학습 흐름을 화면에 보여주어, 학습이 중단되지 않는 경험을 만들고자 했습니다.

학습 과정에서는 단계별 난이도를 다르게 구성해 사용자가 같은 문장을 반복하더라도 학습 목적이 달라지도록 설계했습니다. 단순히 따라 말하는 것이 아니라, 듣고 이해하고, 자막을 참고하고, 일부 정보를 가린 상태에서 회상하고, 마지막에는 스스로 발화하는 흐름을 만들었습니다. 이를 통해 쉐도잉의 핵심인 반복 학습이 지루한 반복이 아니라 점진적인 훈련으로 느껴지도록 하고자 했습니다.

AI 피드백 화면을 설계할 때는 많은 정보를 보여주는 것보다, 사용자가 바로 이해하고 다음 행동으로 옮길 수 있는 정보 구조를 만드는 데 집중했습니다. LLM이 생성한 모든 내용을 나열하기보다, 사용자가 확인해야 할 발음, 억양, 속도, 표현 정보를 우선순위에 따라 배치했습니다. 최종 점수 역시 단순한 결과값이 아니라, 사용자가 자신의 발화를 납득하고 개선 방향을 찾을 수 있도록 최대한 객관적인 기준으로 보여주고자 했습니다.

학습 이후에는 복습 버튼, 학습 통계, 스탬프와 같은 요소를 통해 사용자가 학습 결과를 확인하고 다시 돌아올 수 있도록 설계했습니다. 쉐도잉은 한 번의 학습보다 반복과 복습이 중요한 학습 방식이기 때문에, 결과 확인에서 끝나는 것이 아니라 다음 학습으로 이어지는 동선을 만드는 것이 중요하다고 판단했습니다.

게이미피케이션 기능 역시 단순한 재미 요소가 아니라 학습 지속성을 보완하기 위한 장치로 설계했습니다. 지나치게 어렵거나 게임 자체에만 몰입하게 만들기보다, 기존 쉐도잉 학습 방식을 기반으로 익숙한 학습 과정을 유지했습니다. 여기에 캐릭터의 마음을 사로잡는 테마와 다른 사용자와의 경쟁 요소를 더해, 사용자가 반복 학습을 조금 더 가볍게 받아들이고 지속할 수 있도록 했습니다.

기획과 디자인을 맡으며 가장 크게 느낀 점은, 사용자의 이용 흐름을 중심에 두어야 서비스의 방향이 흔들리지 않는다는 것이었습니다. 기능을 개별적으로 바라보면 추가하고 싶은 요소가 계속 늘어나지만, 사용자가 어떤 목적을 가지고 들어와 어떤 과정을 거쳐 학습을 완료하고 다시 복습으로 돌아오는지를 기준으로 보면 필요한 기능과 덜어내야 할 기능을 구분할 수 있었습니다.

다만 실제 사용자의 피드백을 충분히 받지 못한 점은 아쉬움으로 남았습니다. 사용자 흐름을 중심으로 기능과 화면을 설계했기 때문에, 실제 학습자가 이 흐름을 자연스럽게 느끼는지, AI 피드백을 이해하고 다시 학습으로 이어지는지 검증해보고 싶었습니다. 그러나 개발 일정상 사용자 테스트까지 진행하지 못했고, 이로 인해 기획 단계에서 세운 가설을 실제 사용 경험으로 확인하지 못한 점이 아쉬웠습니다. 다음 프로젝트에서는 기능 구현 자체를 목표로 삼기보다, 실제 사용자 피드백을 받는 것을 1차 목표로 두고 서비스를 설계해보고 싶습니다.

## 향후 개선 사항

- 발음 유사도 분석 기준 고도화를 통한 더 정교한 피드백 제공
- 억양 및 리듬 분석 결과를 시각화하여 사용자가 차이를 쉽게 이해할 수 있도록 개선
- 사용자의 수준에 따른 콘텐츠 추천 기능 도입
- 학습 패턴 기반 개인화 복습 주기 제공
- 학습 리그와 랭킹 기능을 고도화하여 장기적인 학습 동기 강화
- 다양한 영어 시험 및 회화 목적에 맞춘 학습 모드 확장
